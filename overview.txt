# Auto Article Generator - Project Overview

## Completed Features

### Core Functionality
✅ Google Trends Integration
- Implemented Python service for fetching trending topics
- Added fallback topics for API issues
- Filters out sports-related topics

✅ Article Generation
- Integrated with Perplexity API for content generation
- Structured article format with title, excerpt, and content
- Added metadata and timestamps

✅ Image Integration
- Implemented Pexels API integration
- Added featured images to articles
- Proper image attribution and credits

✅ Content Storage
- JSON-based article storage system
- Organized file structure in data/articles
- Caching system for processed topics

### Frontend

- Search functionality

- Backend: Node.js
- CMS: Headless WordPress
- APIs:

  - Google Trends (Topic Discovery)
  - Pexels (Images)
  - WordPress REST API
- Deployment: Vercel (planned)
- CMS Hosting: Cloudways (WordPress)
